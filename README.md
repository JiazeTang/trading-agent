# riskeval：QQQ 分市况风险评估

先评估 QQQ 在上涨、震荡、下跌三类市况下的风险，再逐个检验交易策略。
数据用 30 分钟 K 线，只看常规交易时段（美东 9:30–16:00），每天 13 根。

## 路线图

| 里程碑 | 内容 | 状态 |
| --- | --- | --- |
| 1 | 数据、市况划分、买入持有风险基线 | ✅ 代码完成，等真实数据跑第一次 |
| 2 | 纸面分析策略：每个策略写一页说明（逻辑、规则、≤3 个参数、事先预测），放在 `strategies/` | 下一步 |
| 3 | 回测引擎，只在开发集上跑 | |
| 4 | 留出集只跑一次，出最终报告 | |

## 防过拟合的规矩（已写死，不因结果修改）

- **市况标签**：按自然季度切分，季度收益 > +8% 为 `up`，< −8% 为 `down`，其余为 `sideways`。
  标签要等季度结束才知道，只能用来给结果分组，**绝不能作为策略的输入**。
- **开发集 / 留出集**：每类市况内按时间交替分配，第 1、3、5… 个季度是 `dev`，第 2、4、6… 个是 `holdout`。
  不完整的季度（如当前季度）标为 `excluded`，不参与评估。
- **策略先写说明再回测**：规则和参数在跑第一次回测前定下，预测也写下来。
- **留出集只在最后跑一次**；所有尝试过的版本都要记录，包括失败的。

## 快速开始

1. 在 [Alpaca](https://alpaca.markets) 注册免费账户，在 Paper Trading 页面生成 API Key。
2. 设置环境变量（不要把密钥写进代码或提交到仓库）：
   ```bash
   export APCA_API_KEY_ID=你的KeyID
   export APCA_API_SECRET_KEY=你的SecretKey
   ```
3. 安装并运行：
   ```bash
   pip install -e ".[dev]"
   python -m riskeval.baseline            # 第一次会下载 2016 年至今的数据并缓存到 data/
   python -m riskeval.baseline --refresh  # 以后想更新数据时
   pytest                                 # 单元测试，用合成数据，不需要密钥
   ```

价格使用拆股 + 分红复权（`adjustment=all`）。每次分红都会改写历史价格，所以更新数据时整份重新下载，不做增量追加。

## 输出指标

亏损类指标都用负数表示。

| 列 | 含义 |
| --- | --- |
| `total_return` | 季度收益 |
| `ann_vol` / `downside_vol` | 年化波动 / 年化下行波动（由 30 分钟收益算出） |
| `max_drawdown` | 季度内最大回撤（按 30 分钟收盘价，能看到盘中回撤） |
| `max_dd_days` | 最长一次处于回撤中跨越的交易日数 |
| `var95_daily` / `cvar95_daily` | 日度 95% VaR / CVaR；汇总表里把同类季度的所有交易日合并计算 |
| `worst_day` / `worst_bar` | 最差单日 / 最差单根 K 线 |

## 目录

```
src/riskeval/
  sessions.py   NYSE 交易日历（含提前收盘日）
  data.py       Alpaca 下载、常规时段过滤、缓存、数据质量检查
  regimes.py    季度市况标签 + 开发集/留出集划分
  metrics.py    风险指标、按季度/按市况汇总
  baseline.py   里程碑 1 的命令行入口
tests/          单元测试（合成数据）
```

## 已知局限

- 按季度收益打标签：一个季度先暴跌再反弹，可能被标成震荡。
- Alpaca 免费的 SIP 历史数据从 2016 年开始，下跌季度只有少数几个，结论要留余量。
