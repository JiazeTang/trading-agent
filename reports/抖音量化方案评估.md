## "一年 640 亿"的验算

- **用它自己步骤 2 的参数**（μ=15%、σ=20%、r=3%）：步骤 10 的公式给出年增长 19.7%。要一年净赚 640 亿，本金需要约 **3,245 亿**。
- **用它自己步骤 7 的回测数字**（SR 3.42、年化 62.5%，隐含波动 17.4%）：满凯利杠杆是 **19.7 倍**，公式给出一年增长 **347 倍**，本金只要约 1.85 亿就能"变成" 640 亿。这很可能就是 640 亿的来源。
- **为什么这在现实里做不到**：
  1. 19.7 倍杠杆下，标的单日下跌 5.1% 就会亏光本金。我们回测过的半导体股，最差单日跌幅超过 9%。
  2. 回测 Sharpe 几乎总是被高估。真实 SR 只有 1 时，按回测数字满凯利一年会亏掉约 91%；真实 SR 为 0.5 时亏掉约 98%。
  3. 加上肥尾（日收益用自由度 3 的 t 分布）、真实 SR=1 的蒙特卡洛：满凯利一年后 **48% 的路径归零**，中位数只剩本金的 1.5%；1/4 凯利归零比例 0.8%；不加杠杆不会归零，中位收益约 17%。
  4. 资金容量有限：策略规模越大，冲击成本越高，Sharpe 越低。大奖章基金把规模限制在约 100 亿美元，就是这个原因。
  5. 券商和监管不会给散户近 20 倍的股票杠杆。
- 搜索"一年 640 亿 量化"没有找到任何量化机构的对应报道。

## 可以借鉴到我们项目里的

1. **概率夏普比（PSR）和紧缩夏普比（DSR）**：给规则 A 和当前方案的日收益算 PSR，并把所有试过的变体计入 DSR。成本几乎为零。
2. **凯利只当上限**：凯利仓位 = Sharpe ÷ 波动。半导体波动约 30%，按打过折的 Sharpe（0.7 到 1）算，满凯利大约 2 到 4 倍，1/4 凯利大约 0.5 到 1 倍。我们不加杠杆、留现金，大致在 1/4 到 1/2 凯利之间，不该再往上加。（2026-10-27 更正：原先按抖音例子的 17.4% 波动算出"已低于 1/4 凯利"，不适用于半导体。）
3. **蒙特卡洛风险模拟**：对规则 A 的真实交易记录做重抽样，得到最大回撤和连续亏损的分布，用来事先定好"什么情况下停用策略"。
4. **机器学习预测（可选实验）**：用价格和成交量特征，在 16 只半导体和 S&P 500 上做严格的滚动样本外检验。按学术结果，预期 R² 不到 1%，扣成本后很可能没有优势，适合作为学习用的实验。

## 验算脚本

```python
from math import exp
mu, sigma, r = 0.15, 0.20, 0.03
print((mu - r) / sigma**2)                       # 3.0 倍凯利杠杆
g = (mu - r)**2 / (2 * sigma**2)                 # 0.18
print(640 / (exp(g) - 1))                        # 约 3245（亿）
sr, ann = 3.42, 0.625
vol = (ann - r) / sr                             # 0.174
print(sr / vol, exp(sr**2 / 2), 640 / exp(sr**2 / 2))   # 19.7 倍，347 倍，约 1.85（亿）
```
